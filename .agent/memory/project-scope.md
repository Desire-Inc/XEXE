# XEXE Project Scope Memory

XEXE is a unified coding-agent platform built on top of Cline.

Core inspirations:

- Cline: base, SDK, IDE, CLI, MCP, Plan/Act, multi-agent teams.
- Claw Code: Rust/runtime discipline, doctor checks, parity docs, Windows care.
- 1Code: worktree isolation, desktop UX, Kanban, diff preview, background agents.
- Aider: repo-map, surgical edits, Git-first workflow, lint/test loop.
- Forge: terminal workflow, `:` commands, agent roles, semantic search, skills.
- Goose: multi-provider, MCP extensions, custom distributions.
- OpenCode: simple build/plan/general UX.
- Windsurf resources: rules, memories, prompts, practical safety guidance.
- IDK2/notion-cli: agent-friendly CLI, JSON output, Markdown I/O, single-binary ergonomics.

Initial implementation target: modular MVP foundation with task orchestration, worktree manager, workspace indexer, memory loader, provider router, MCP registry, tool policies, automations, and a standalone CLI.
